Python re 正则表达式速查表

先决定要找、验、拆还是替换，再组合「字符 × 次数 × 位置」。以下示例使用 Python 3.14 的字符串规则。

import re
s = "Que_53.py 与 Que_100.py"

按任务选函数

用途 / 写法Python 表达式实际结果
search · 找第一处从任意位置开始找。成功返回 Match，失败返回 None。re.search(r"\d+", s).group()'53'
match · 从开头找只尝试字符串开头。这里开头是 Q。re.match(r"\d+", s)None
fullmatch · 验整串整串都符合规则才成功。校验时可直接用 bool。bool(re.fullmatch(r"Que_[0-9]+\.py", "Que_53.py.bak"))False
findall · 取全部按出现顺序收集互不重叠的匹配。找不到返回 []。re.findall(r"\d+", s)['53', '100']
finditer · 取文字和位置迭代得到 Match；span() 的右端不包含在匹配中。[(m.group(), m.span()) for m in re.finditer(r"\d+", s)][('53', (4, 6)), ('100', (16, 19))]
sub · 替换参数顺序是规则、替换内容、原文。count=1 只替换第一处。re.sub(r"\d+", "#", s, count=1)'Que_#.py 与 Que_100.py'
split · 拆分按规则切开字符串。分隔符用捕获组包住时也会出现在结果里。re.split(r"[,，\s]+", "苹果,桃子 西瓜")['苹果', '桃子', '西瓜']
compile · 复用规则保存规则后可直接调用其方法，例如 rx.findall(s)。re.compile(r"\d+").findall(s)['53', '100']
escape · 按字面查找把待查文本中的正则特殊字符转义，适合查用户输入的原文。re.search(re.escape("a+b"), "算式 a+b").group()'a+b'

匹配什么字符

用途 / 写法Python 表达式实际结果
普通字符 / 转义普通字母匹配自身；点号前加反斜杠可匹配字面上的点。re.findall(r"\.py", "a.py bXpy")['.py']
. · 任意一个字符默认跳过换行符。re.findall(r".", "甲\n乙")['甲', '乙']
\d / \D十进制数字 / 非十进制数字。只要半角数字时写 [0-9]。re.findall(r"\d+", "Q５３ / Q53")['５３', '53']
\w / \WUnicode 字母、数字及下划线 / 这些字符以外的字符。汉字也能匹配。re.findall(r"\w+", "小鸟_7!")['小鸟_7']
\s / \S空白 / 非空白。空格、换行、制表符都属于空白。re.findall(r"\S+", "a\tb c")['a', 'b', 'c']
[abc] / [a-z]集合中任选一个；连字符可指定范围。re.findall(r"[a-zA-Z]", "Q53苹果")['Q']
[^abc] · 排除集合方括号开头的 ^ 表示排除。re.findall(r"[^,，]+", "苹果,桃子，西瓜")['苹果', '桃子', '西瓜']

重复几次

用途 / 写法Python 表达式实际结果
＊ / ＋写代码用半角 * 和 +。前者允许零次，后者至少一次。都只修饰前一个字符或组。(re.findall(r"ab*", "a abb"), re.findall(r"ab+", "a abb"))(['a', 'abb'], ['abb'])
? · 零次或一次适合可有可无的部分。re.findall(r"colou?r", "color colour")['color', 'colour']
{n} / {m,n} / {m,}恰好 n 次 / 至少 m 至多 n 次 / 至少 m 次。re.findall(r"[0-9]{2,3}", "1 23 456")['23', '456']
贪婪 / 非贪婪默认在能完成匹配的前提下尽量多取；量词后再加 ? 会尽量少取。(re.findall(r"<.*>", "<a><b>"), re.findall(r"<.*?>", "<a><b>"))(['<a><b>'], ['<a>', '<b>'])

位置、分组与取值

用途 / 写法Python 表达式实际结果
^ / $ · 首尾默认匹配字符串开头 / 结尾；$ 也能匹配末尾换行符之前。re.findall(r"^Q\d+$", "Q53\n")['Q53']
\b · 单词边界匹配位置。常见于英文整词查找，汉字间通常没有这种边界。re.findall(r"\bcat\b", "cat cats cat!")['cat', 'cat']
A|B · 二选一从左到右尝试，先成功的分支优先。re.findall(r"cat|dog", "cat and dog")['cat', 'dog']
(...) · 捕获group(0) 是整段；group(1) 是第一个捕获组；groups() 返回各组。re.fullmatch(r"(Que)_(\d+)\.py", "Que_53.py").groups()('Que', '53')
findall 遇到捕获组零组返回整段，一组返回组内文字，多组返回元组。re.findall(r"Que_(\d+)\.py", s)['53', '100']
(?:...) · 只分组让几个字符作为整体重复，同时保留 findall 的整段结果。re.findall(r"(?:ab)+", "abab ab")['abab', 'ab']
(?P<name>...) · 给组起名用名字取值，也能在替换字符串中用名字引用。re.sub(r"Que_(?P<num>\d+)", r"题号\g<num>", "Que_53")'题号53'
(?=...) / (?!...) · 看右边要求右侧符合 / 不符合条件，右侧内容不计入本次匹配。re.findall(r"[0-9]+(?=元)", "12元 3个")['12']

改变匹配方式的 flags

用途 / 写法Python 表达式实际结果
re.I · 忽略大小写适合大小写混用的英文文本。re.findall(r"cat", "Cat CAT", flags=re.I)['Cat', 'CAT']
re.M · 多行让 ^ 和 $ 也能匹配每一行的开头和结尾。re.findall(r"^\d+", "12甲\n34乙", flags=re.M)['12', '34']
re.S · 点号跨行让 . 也匹配换行。多个标志可用 | 组合。re.findall(r"a.b", "a\nb", flags=re.S)['a\nb']
re.A · 限定 ASCII用于 str 规则时，让数字、单词字符等类别按 ASCII 匹配。re.findall(r"\d+", "５３ / 53", flags=re.A)['53']

三个容易混淆的小地方

① 搜索前先想好范围。 从文件名提取题号用 search；判断整个文件名合不合规用 fullmatch。search 可能返回 None，取值前先写 if m:。
② 原始字符串保留反斜杠。 写 r"\bcat\b"，Python 会把反斜杠交给正则引擎；普通字符串里的 "\b" 会被 Python 读成退格符。
③ 对照「找到什么」。 [ab] 匹配一个 a 或 b，(ab) 匹配连续的 ab 并捕获它。
